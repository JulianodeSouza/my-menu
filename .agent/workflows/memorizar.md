# Workflow: /memorizar

Verifique o estado atual do repositório (incluindo `git diff` / `git status` e commits recentes, se disponíveis), revise os arquivos em `memory-bank/` e consolide/limpe informações antigas para manter `memory-bank/arquitetura.md`, `memory-bank/decisoes.md` e `memory-bank/contexto-atual.md` atualizados, curtos e sem duplicidades.
