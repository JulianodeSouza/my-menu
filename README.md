# 🛒 My Menu

Aplicativo mobile desenvolvido para facilitar a organização de listas de compras de supermercado, oferecendo mais planejamento, controle de itens e acompanhamento de gastos durante a compra.

---

## 📌 Sobre o projeto

O **My Menu** foi criado com foco em praticidade no dia a dia.  
A proposta é permitir que o usuário monte sua lista de compras, edite itens quando necessário e acompanhe os preços para visualizar o total da compra em tempo real.

---

## ✨ Funcionalidades

- ✅ **Inclusão de produtos**  
  Adicione quantos itens desejar à lista, com controle de quantidade.

- ✅ **Listagem de produtos**  
  Visualize todos os itens cadastrados com suas respectivas quantidades.

- ✅ **Edição de produtos**  
  Altere nome e quantidade de um item já inserido.

- ✅ **Exclusão de produtos**  
  Remova produtos da lista de forma simples.

- ✅ **Informar preço dos itens**  
  Ao marcar um produto como pego, informe quantidade real e preço, com soma automática no valor total da compra.

## 🚀 Como executar o projeto

> Pré-requisitos: ambiente React Native configurado (Node.js, npm/yarn e ferramentas Android/iOS).

```bash
# 1) Clone o repositório
git clone https://github.com/JulianodeSouza/my-menu.git

# 2) Acesse a pasta do projeto
cd my-menu

# 3) Instale as dependências
npm install
# ou
yarn
```

### Executar no Android
```bash
npx react-native run-android
```

### Executar no iOS
```bash
npx react-native run-ios
```

### Iniciar o Metro Bundler
```bash
npx react-native start
```

## 📱 Objetivo de uso

O app foi pensado para usuários que desejam:

- organizar melhor as compras do mês;
- evitar esquecimentos no supermercado;
- controlar os gastos enquanto compram;
- ajustar quantidades e preços conforme itens são coletados.
